# 浜松市オープンデータ MCP 利用ガイド

GitHub Pagesで公開するための単体ページ。サイトのトップページは `index.html`。

## 公開方法

1. このディレクトリの `index.html` と `README.md` だけを、新しいGitHubリポジトリへ登録する。
2. リポジトリの **Settings → Pages** を開く。
3. 公開元を `Deploy from a branch`、ブランチを `main`、フォルダを `/(root)` に設定する。
4. 表示されたGitHub Pages URLでページを確認する。

このページはインターネット上で誰でも閲覧できる前提。MCPトークンや非公開のAWS設定は含めない。
