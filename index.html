利用ガイド

浜松市のデータを、
AIアシスタントと探そう

浜松市が公開するオープンデータを、CodexやClaude Codeから検索・取得できるサービスだよ。使い始める前に、利用できるデータとトークンの準備方法を確認しよう。

カタログ登録354件｜2026年11月3日時点

これはなに？

AIアシスタントが浜松市オープンデータを扱うための、MCP（Model Context Protocol）サーバーだよ。

チャットで「浜松市の避難所を探して」「子育て支援ひろばの開館日を見せて」と頼むと、AIアシスタントがデータセットを検索し、公開元にあるJSONデータを取得する。回答に使ったデータの出典やURLも確認できるよ。

接続URL
https://hamamatsu-opendata-mcp.code4hamamatsu.org/mcp

MCPクライアントからAPI GatewayとAWS Lambdaを通じて浜松市の公開データへアクセスする構成。接続には個人ごとのBearerトークンが必要。

どんなデータが使える？

対応表に登録された354件のうち、JSON形式で配布されているデータを検索・取得できるよ。カテゴリから探すか、タイトルやキーワードで検索してね。

  • 防災避難所、防災ヘリポート、自主防災組織 など
  • 統計人口や市政に関する統計データ など
  • 福祉・医療障害福祉サービス事業所、医療・福祉関連情報 など
  • 子育て子育て支援ひろば、保育・子育て関連情報 など
  • くらしごみ分別、公的な生活情報 など
  • 施設・消防都市公園、自転車駐車場、消防水利施設 など

例：「浜松市の避難所を探して」「ごみの分別方法を調べて」「近くの都市公園一覧を見せて」など、知りたい内容を普段の言葉で頼めるよ。

登録データがすべての公開データを網羅するわけではないよCSVなどJSON以外の形式、対応表に未登録のデータ、公開元で利用できないデータは対象外。検索で見つからない場合は、浜松市の公式オープンデータカタログも確認してね。

AIが使う3つの機能

検索から取得まで、AIアシスタントが必要な機能を選んで呼び出すよ。

search_datasets

データセットを検索

タイトル・ID・カテゴリから候補を探す。

get_dataset

出典と配布先を確認

データセットの説明や公式カタログURLを確認する。

fetch_dataset

最新版のJSONを取得

公開元を照合してJSONを取得。キーワードで行を絞り込める。

利用にはトークン発行が必要

URLを設定するだけでは接続できないよ。アクセス許可を受けて、あなた専用のトークンを発行してもらおう。

  1. 管理者へ利用申請利用する人の識別名と、CodexまたはClaude Codeのどちらを使うかを伝える。
  2. 個人用トークンを受け取る発行されたトークンは、パスワードと同じように安全に保管する。
  3. クライアントに設定下の手順でMCPサーバーとトークンを登録する。
  4. 接続を確認ツール一覧に3つの機能が表示されたら準備完了。

申請先：このページを案内したサービス管理者に、利用者IDと利用するクライアントを伝えてね。トークンはこのページから自分で発行できないよ。

設定方法

トークンを受け取ったら、利用するクライアントの手順に沿って設定しよう。URLとトークンの両方が必要。

Codex

Codexの ~/.codex/config.toml に、次の設定を追加する。接続確認できた設定方法は、Authorizationヘッダーにトークンを指定する形だよ。

[mcp_servers.hamamatsu-opendata]
url = "https://hamamatsu-opendata-mcp.code4hamamatsu.org/mcp"
http_headers = { "Authorization" = "Bearer ここに発行されたトークン" }

設定後にCodexを再起動し、MCPサーバーの状態が connected になることを確認。設定ファイルに生トークンを保存するため、このファイルは共有・コミットせず、閲覧できる人を自分に限定してね。

Claude Code

プロジェクトのルートにある .mcp.json に設定する。トークンを環境変数 HAMAMATSU_MCP_TOKEN に入れてからClaude Codeを起動してね。

{
  "mcpServers": {
    "hamamatsu-opendata": {
      "type": "http",
      "url": "https://hamamatsu-opendata-mcp.code4hamamatsu.org/mcp",
      "headers": {
        "Authorization": "Bearer ${HAMAMATSU_MCP_TOKEN}"
      }
    }
  }
}

macOS・Linuxの例：ターミナルで export HAMAMATSU_MCP_TOKEN='発行されたトークン' を実行してからClaude Codeを起動。`.mcp.json` は環境変数の参照を保持し、生トークンを書き込まないようにする。

対応しているクライアント

このトークン認証方式で接続確認できているクライアントを使ってね。

利用できる

Codex、Claude Code

リモートMCPサーバーとして接続する。

現在は利用できない

Claude Desktop、ChatGPT

現在の固定Bearerトークン方式では接続できない。対応するには別の認証方式が必要。

つながらないとき

  • 有効なトークンが設定されているか確認する。前後の空白や改行を含めない。
  • トークンを再発行した場合は、新しいトークンをクライアントへ設定する。
  • Codexは設定変更後に再起動し、MCPサーバーの状態を確認する。
  • 解決しない場合は、トークンそのものを送らずに管理者へ相談する。
