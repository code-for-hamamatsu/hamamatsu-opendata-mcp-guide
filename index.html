利用ガイド

浜松市のデータを、
AIアシスタントと探そう

浜松市が公開するオープンデータを、対応するAIアシスタントから検索・取得できるMCPサーバーだよ。接続URLを登録すれば、すぐに使い始められるよ。

カタログ登録354件｜2026年11月3日時点

これはなに？

AIアシスタントが浜松市オープンデータを扱うための、MCP（Model Context Protocol）サーバーだよ。

チャットで「浜松市の避難所を探して」「子育て支援ひろばの開館日を見せて」と頼むと、AIアシスタントがデータセットを検索し、公開元にあるJSONデータを取得する。回答に使ったデータの出典やURLも確認できるよ。

接続URL
https://hamamatsu-opendata-mcp.code4hamamatsu.org/mcp

API Gatewayの流量制限とLambdaの同時実行数制限を設定しているよ。

どんなデータが使える？

対応表に登録された354件のうち、JSON形式で配布されているデータを検索・取得できるよ。カテゴリから探すか、タイトルやキーワードで検索してね。

  • 防災避難所、防災ヘリポート、自主防災組織 など
  • 統計人口や市政に関する統計データ など
  • 福祉・医療障害福祉サービス事業所、医療・福祉関連情報 など
  • 子育て子育て支援ひろば、保育・子育て関連情報 など
  • くらしごみ分別、公的な生活情報 など
  • 施設・消防都市公園、自転車駐車場、消防水利施設 など

例：「浜松市の避難所を探して」「ごみの分別方法を調べて」「近くの都市公園一覧を見せて」など、知りたい内容を普段の言葉で頼めるよ。

登録データがすべての公開データを網羅するわけではないよCSVなどJSON以外の形式、対応表に未登録のデータ、公開元で利用できないデータは対象外。検索で見つからない場合は、浜松市の公式オープンデータカタログも確認してね。

AIが使う3つの機能

検索から取得まで、AIアシスタントが必要な機能を選んで呼び出すよ。

search_datasets

データセットを検索

タイトル・ID・カテゴリから候補を探す。

get_dataset

出典と配布先を確認

データセットの説明や公式カタログURLを確認する。

fetch_dataset

最新版のJSONを取得

公開元を照合してJSONを取得。キーワードで行を絞り込める。

利用方法

MCPに対応したクライアントへ接続URLを登録するだけ。アカウント申請やトークンの発行は必要ないよ。

接続URL

https://hamamatsu-opendata-mcp.code4hamamatsu.org/mcp

接続方式は「リモートMCP」または「Streamable HTTP」を選んでね。認証方式の選択やAuthorizationヘッダーの入力は不要。

Claude Desktopでは「Settings → Connectors」からカスタムコネクターを追加。ChatGPTでは、利用可能なプラン・ワークスペースでWeb版の設定からカスタムMCPアプリを作成してURLを登録するよ。利用できる機能や画面はアカウント設定によって異なる場合がある。

接続後：ツール一覧に search_datasets、get_dataset、fetch_dataset が表示されたら準備完了。

クライアントへの登録例

各クライアントでリモートMCPサーバーを追加し、上のURLを登録してね。

Codex CLI

codex mcp add hamamatsu-opendata --url https://hamamatsu-opendata-mcp.code4hamamatsu.org/mcp

Claude Code

プロジェクトの .mcp.json に以下を設定する。

{
  "mcpServers": {
    "hamamatsu-opendata": {
      "type": "http",
      "url": "https://hamamatsu-opendata-mcp.code4hamamatsu.org/mcp"
    }
  }
}

Claude Desktop・ChatGPT

Claude Desktopは「Settings → Connectors」からカスタムコネクターを追加。ChatGPTはカスタムMCPアプリの作成画面でURLを登録する。ChatGPT側はプランやワークスペースの管理者設定により利用できない場合があるよ。

対応クライアント

リモートMCPまたはStreamable HTTPに対応したクライアントから利用できるよ。

接続先

浜松市オープンデータ MCP

認証なしの公開リモートMCPサーバー。接続にトークンは不要。

利用条件

クライアント側の機能提供状況による

ChatGPTなどはプランやワークスペース設定でカスタムMCP機能が制限される場合があるよ。

つながらないとき

  • 接続URLの末尾が /mcp になっているか確認する。
  • 接続方式にリモートMCPまたはStreamable HTTPを選んでいるか確認する。
  • API Gatewayの共有レート制限に達すると、一時的にリクエストが制限される場合があるよ。少し待ってから試してね。
  • ChatGPTはプランやワークスペース管理者の設定により、カスタムMCP機能を使えない場合がある。
